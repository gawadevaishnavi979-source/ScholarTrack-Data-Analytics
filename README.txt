# ScholarTrack Starter Project

## What is included?
- `scholartrack_applications_raw.csv`: 505 rows of synthetic (made-up) scholarship application records, including a few intentional data-quality issues.
- `step1_preview.py`: beginner script to load and inspect the dataset.
- `requirements.txt`: Python libraries used in later steps.

## Step 1: Set up
1. Extract this ZIP into a folder named `ScholarTrack_Starter`.
2. Open the folder in VS Code or your Python editor.
3. Open a terminal in that folder.
4. Install libraries:
   `python -m pip install -r requirements.txt`
5. Run:
   `python step1_preview.py`

If `python` does not work on Windows, try `py step1_preview.py`.

## Important
All records are synthetic and fictional. Do not describe the data as real government scholarship data.
